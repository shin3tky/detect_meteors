# 恒星位置合わせ付きの流星検出

`star_registration` フックを有効にすると、ROI 内の恒星から直前画像の回転と平行移動を推定し、
現在画像の座標に合わせます。その画像ペアを 1.6.13 ベースのハフ検出に渡し、
候補 RAW のコピー、デバッグ画像の出力、進捗の記録を行います。必要に応じて
`aircraft_trail` による光跡解析も併用できます。

## 実行方法

[航空機サンプルの RAW](INSTALL_ja.md#サンプル-raw-画像) を
`rawfiles/2024GEMINI_AIRCRAFT` に用意し、リポジトリのルートから実行します。
サンプル設定には空の ROI、ハフの閾値、位置合わせと航空機光跡の両フックが入っています。

```bash
uv run detect-meteors --config config_examples/star_registration_sample.yaml --debug-image
```

ほかの撮影系列で使う場合は、同じカメラの連続露光を対象にし、木や地上物を除いた、
恒星が画像内に広く分布する ROI を選びます。座標は 2×2 ビニング後の画素単位です。
対話的に ROI を選ぶ場合は、次のように位置合わせフックを指定できます。

```bash
uv run detect-meteors --target ./rawfiles --hooks star_registration --debug-image
```

`--hooks` は設定ファイルのフック一覧を上書きします。両方を指定する場合は
`--hooks star_registration,aircraft_trail` を使います。`--no-roi` で全画面を使う場合は、
恒星の探索範囲も全画面になります。

## 位置合わせと再開

- 隣接ペアごとに ROI 内の恒星の重心を取り、12 px 以内の相互最近傍を対応付けます。
  試作の RANSAC で外れ値を除き、スケール 1 の回転・平行移動を求めます。検出時は
  すべての対応点を推定に使い、試作の評価コードでは一部を評価用に確保します。
- 対応が16点以上あり、RANSAC の採用点が14点以上かつ対応数の半分（切り捨て）以上で、
  採用点が縦横それぞれ420 px以上に分布し、回転が ±0.5° 以内の場合に変換を適用します。
  直前画像を双一次補間し、補間に使う全画素が元の ROI 内にある領域と現在の ROI が重なる
  範囲を検出に使います。現在画像の座標で線分とデバッグ画像を出力します。
- 条件を満たさない場合や有効領域が空の場合は、そのペアを元の画像と ROI で検出します。
  `--no-parallel --verbose` で、適用の有無、対応点数、適用時の変換行列を確認できます。
  Python の出力ハンドラーからは `context["metadata"]["star_registration"]` で参照できます。
- 同じ設定で実行すると進捗から再開できます。位置合わせの有効化、無効化、フック設定の
  変更時は、別の進捗として画像ペアを処理し直します。条件を比較するときは、出力先、
  デバッグ画像の保存先、進捗ファイルを条件ごとに指定できます。
- 入力形式は同じ形状の2次元の `uint16` または正規化済み `float32` です。
  `--auto-params` は元画像で閾値を推定し、`--analyze-image` は検出器単体で再現します。
  位置合わせ込みの判定は通常の検出コマンドで確認してください。

## ローカル検証

航空機サンプル12枚の隣接11ペアを、サンプル設定の ROI と閾値で実行しました。
逐次実行では11ペアすべてで変換が成立しました。逐次と2ワーカーの並列で、
候補のファイル名、検出値、デバッグ画像が一致し、候補 RAW の SHA-256 は元ファイルと一致しました。
処理済み8ペアの進捗から再開すると残り3ペアを処理し、検出値とデバッグ画像を再現できました。

| 条件 | 候補 RAW | 既知の流星画像 |
| --- | --- | --- |
| 位置合わせあり | `_C140338.ORF`、`_C140339.ORF`、`_C140344.ORF`、`_C140345.ORF` | 2枚 |
| 位置合わせなし（同じ ROI と閾値で `--hooks aircraft_trail`） | `_C140338.ORF`、`_C140339.ORF`、`_C140344.ORF` | 2枚 |

この条件では位置合わせにより候補が1枚増えました。恒星の残差や別の RAW 系列での結果は
[試作の評価](star_registration_evaluation_ja.md)を参照してください。
