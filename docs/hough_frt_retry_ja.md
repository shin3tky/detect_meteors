# 正の差分ハフで棄却したペアのFRT再検査

同じ121ペアで、位置合わせなしの正の差分ハフが候補にした3枚を採用し、残る118ペアを
[試作済みの全画面FRT](frt_evaluation_2.0.1_ja.md)に渡した。FRTの入力は、試作と同じ
未整列の現在・直前RAWから求めた符号付き差分だった。ハフとFRTは、前回と同じ
16 px収縮済みの空のROIを使用した。[前回の取りこぼし診断](hough_faint_meteor_recovery_ja.md)

## 評価方法

- 航空機サンプル11ペア、2021GEMINI 35ペア、2024GEMINI後半75ペアを計測した。
  RAW、目視ラベル、ROIは前回と照合した。全121ペアで流星6枚、陰性115枚だった。
- ハフは差分9 DN、最小面積3 px²、最小縦横比3.0、最小線スコア30 pxを使った。
  ハフが棄却したペアに対し、FRTの長さ・ROI・正の画素率の条件を維持し、正規化得点
  `min_snr` だけを選んだ。各ペアは、条件を満たすFRT線分が1本以上あれば候補に入る。
- 評価対象の系列を外し、残り2系列の陰性ペアの最高得点を超える最小の下限を選んだ。
  得点と下限が等しい線分も採用する実装なので、最高得点そのものは除外する。
  評価対象の線分にも同じ下限を適用し、出現ペアで注釈軸を50%以上覆った場合を回収とした。
  設定を上げると採用線分は減るため、この条件下で最も緩い下限を使った。

## 実測結果

| 方式 | 流星が写る候補画像 | 出現ペアで軸が一致した流星 | 偽陽性 |
| --- | ---: | ---: | ---: |
| 正の差分ハフのみ | 3/6 | 3/6 | 0/115 |
| FRT再検査・試作の固定下限8 | 6/6 | 6/6 | 115/115 |
| FRT再検査・評価系列を外して下限を選択 | 5/6 | 3/6 | 20/115 |
| FRT再検査・全ラベルを使って偽陽性0枚に調整 | 3/6 | 3/6 | 0/115 |

固定下限8では、取りこぼし3枚とも注釈軸の100%を覆った。118件の再検査がすべて候補に
なったため、同じ設定では候補を絞れなかった。

| 評価対象 | 閾値選択に使った陰性数 | その最高得点（下限は直上） | FRTで追加された流星画像 | 追加の軸一致 | 偽陽性 |
| --- | ---: | ---: | --- | ---: | ---: |
| 航空機サンプル | 106 | 597.792 | なし | 0 | 0/9 |
| 2021GEMINI | 83 | 189.852 | `_C150319.ORF`、`_C150326.ORF` | 0 | 20/32 |
| 2024GEMINI後半 | 41 | 597.792 | なし | 0 | 0/74 |

2021年の2枚では、フレーム内で最も高いFRT得点が189.852を超えたため画像は候補になった。
同じ下限を通った線分の流星軸被覆はどちらも0%だった。2024年後半の
`_C140521.ORF` は、航空機サンプルと2021年の陰性から選ばれた下限を超えなかった。
3枚について、選ばれた下限をFRTに直接設定しても候補判定と被覆が一致した。

| 画像 | フレーム最高得点 | 50%以上の軸被覆を保てる得点下限の最大値 |
| --- | ---: | ---: |
| `_C150319.ORF` | 190.620 | 65.538 |
| `_C150326.ORF` | 193.920 | 42.692 |
| `_C140521.ORF` | 165.916 | 14.549 |

全ラベルを使った確認でも、右列のどの得点下限でも陰性115枚がすべて候補に入った。
この121ペアでは、既存の3枚を維持できたが、試作FRTの得点下限だけで
偽陽性を増やさずに3枚を追加回収できる範囲は得られなかった。

## 再現

[実測 JSON](../experiments/region_comparison/results/hough_frt_retry/hough_frt_retry.json)には
ペアごとのハフ判定、FRT得点、注釈軸付近の線分、各回の閾値と判定結果を保存した。
リポジトリのルートから実行し、`--raw-root` にはRAWの配置先を指定する。

```bash
run_dir=$(mktemp -d)
PYTHONPATH=. uv run --locked python experiments/region_comparison/benchmark_hough_frt_retry.py \
  "$run_dir" --raw-root ../detect_meteors_assets/rawfiles --workers 3
```
